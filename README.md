# DPS Web Designer 🚀

Website institucional e Landing Page de Alta Conversão para a **DPS Web Designer**.

Desenvolvido com **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Lucide Icons** e **Framer Motion**, projetado com estética **Dark Tech**, arquitetura **Mobile-First** e 100% pronto para deploy na **Vercel**.

## 🚀 Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Acesse no navegador
http://localhost:3000
```

---

## ☁️ Como Fazer o Deploy na Vercel

1. Suba o projeto para um repositório no seu **GitHub**, **GitLab** ou **Bitbucket**.
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"**.
3. Importe o repositório `dps-web-designer`.
4. A Vercel detectará automaticamente o framework **Next.js**.
5. Clique em **"Deploy"**. Em menos de 1 minuto seu site estará online com certificado SSL automático!
